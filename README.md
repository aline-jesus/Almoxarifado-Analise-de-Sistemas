## 1. Apresentação do projeto

Este projeto apresenta uma proposta de melhoria para o controle de entrada e saída de materiais do almoxarifado da empresa Qualitymax, localizada na região da Usina Hidrelétrica de Belo Monte, no Pará.

O trabalho reúne as atividades de análise de sistemas desenvolvidas ao longo da disciplina.

## 2. Problema identificado

O almoxarifado utiliza um sistema com leitor de código de barras para registrar materiais e quantidades.

Entretanto, o sistema atual não identifica o colaborador que retirou o material, dificultando o acompanhamento e a rastreabilidade das movimentações.

## 3. Solução proposta

A proposta consiste em um sistema web para melhorar o controle das movimentações do almoxarifado.

As principais funcionalidades previstas são:

- Identificação do colaborador pela matrícula.
- Registro automático de data e hora.
- Cadastro de entradas e saídas de materiais.
- Consulta de movimentações por período e colaborador.
- Cancelamento controlado de registros incorretos.
- Relatórios quinzenais.
- Controle de acesso por perfil de usuário.

O projeto prevê a utilização de Flask e PostgreSQL, mas não inclui implementação funcional nesta etapa acadêmica.
