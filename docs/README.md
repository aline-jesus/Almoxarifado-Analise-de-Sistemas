# Documentação do Projeto — Almoxarifado

## Trabalho 4 — Análise de Sistemas

Este diretório é destinado à organização dos documentos
do projeto de Controle de Entrada e Saída de Materiais
do Almoxarifado da Qualitymax.

## Documentação disponível

O PDF consolidado do Trabalho 4 está na pasta
entrega-final, na página principal do repositório.

O documento contém:

- Levantamento e análise de requisitos.
- Diagramas BPMN AS-IS e TO-BE.
- Diagramas UML.
- Modelo de domínio.
- Arquitetura C4 e decisões ADR.
- Análise de viabilidade e riscos.
- Backlog, MVP e planejamento.
- Protótipo com 10 telas.
- Estratégia de validação.
- Matriz de rastreabilidade.

## Como consultar

Acesse a pasta entrega-final e abra o PDF
do Trabalho 4 para visualizar os artefatos.
